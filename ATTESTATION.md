# Cryptographic Attestation Specification

> **Standard**: in-toto Statement v1.0 + Sigstore / Ed25519 DSSE Envelope  
> **Status**: Production-Ready  
> **Target**: Non-repudiation and chain-of-custody for race condition security findings.

---

## 1. Overview

Every `CONFIRMED` race condition finding generated by RaceProof includes a cryptographically signed **Attestation Bundle** (`attestation.sigstore.json`). This artifact provides cryptographic proof that:
1. The analysis was conducted by an authentic, unmodified instance of RaceProof.
2. The empirical input logs (Burp, HAR, k6, mitmproxy) were processed without tampering.
3. The verdict, defect classification, and counterexample trace were produced under deterministic constraints.

---

## 2. Attestation Format (in-toto v1.0)

RaceProof emits attestations complying with the **in-toto Statement v1.0** specification, encapsulated in a Dead Simple Signing Envelope (DSSE):

```json
{
  "_type": "https://in-toto.io/Statement/v1",
  "subject": [
    {
      "name": "race_condition_evidence_bundle",
      "digest": {
        "sha256": "4a5c6d7e8f901234..."
      }
    }
  ],
  "predicateType": "https://race-proof.org/attestation/v1",
  "predicate": {
    "verdict": "CONFIRMED",
    "defect_class": "LOST_UPDATE",
    "confidence": 0.885,
    "p_value": 0.0001,
    "invariant_violated": "single_200_winner",
    "engine_version": "0.2.0",
    "timestamp": "2026-11-07T12:00:00Z",
    "environment": {
      "python_version": "3.15.2",
      "rust_core_version": "0.2.0",
      "os": "Windows-10-10.0.26100-SP0"
    }
  }
}
```

---

## 3. Cryptographic Signature Envelope

The statement is signed using either:
- **Local Ed25519 Keys**: Hardware security module (HSM) or local offline private key (`ed25519_key.pem`).
- **Sigstore / Fulcio / Rekor**: Keyless OpenID Connect (OIDC) identity binding logged to an immutable transparency ledger.

```json
{
  "payloadType": "application/vnd.in-toto+json",
  "payload": "<Base64-encoded in-toto Statement>",
  "signatures": [
    {
      "keyid": "sha256:pubkey_digest...",
      "sig": "<Base64-encoded Ed25519 Signature>"
    }
  ]
}
```

## 4. Verification Procedure for Third Parties

Auditors, compliance officers, and bug bounty triage teams can verify the integrity of an attestation bundle without installing RaceProof:

### Option A: Using OpenSSL
```bash
# Extract the signed payload and decode from base64
jq -r .payload attestation.sigstore.json | base64 -d > payload.json

# Extract signature
jq -r .signatures[0].sig attestation.sigstore.json | base64 -d > signature.bin

# Verify with public key
openssl pkeyutl -verify -pubin -inkey raceproof_pubkey.pem \
  -sigfile signature.bin -in payload.json
```

### Option B: Using Cosign / Sigstore
```bash
cosign verify-blob \
  --key raceproof_pubkey.pem \
  --signature <(jq -r .signatures[0].sig attestation.sigstore.json | base64 -d) \
  <(jq -r .payload attestation.sigstore.json | base64 -d)
```

### Option C: Using RaceProof CLI
```bash
race-proof verify --attestation ./race_proof_findings/finding_xyz/attestation.sigstore.json
```
Output:
```
[PASS] Cryptographic Attestation VALID
  Signer: security@race-proof.org (Ed25519 Key ID: 8f92e3...)
  Timestamp: 2026-11-07T12:00:00Z
  Integrity: Payload hash matches subject digest
```
